# Bundled fonts

Noto Sans / Noto Serif fonts for Indian scripts, used by the PDF report (and as fallbacks for chart
labels) so names and titles in Hindi, Punjabi, Bengali, Gujarati, Odia, Tamil, Telugu, Kannada and
Malayalam render as text instead of empty boxes. Latin text uses DejaVu Sans, which ships with matplotlib.

Source: the `gh-pages` branches of https://github.com/notofonts (hinted TTF builds).
